# NEX Launavakt

NEX Launavakt is a private-by-design Iceland-focused payslip and pension explanation service. The public website contains the customer interface and browser-side document handling. Uploaded documents are not included in this repository.

## Privacy

The public release does not contain customer documents, payslips, pension statements, databases, access tokens, logs, or private NEX configuration. Documents selected in the browser remain on the user's device unless the interface clearly states otherwise.

## Status

Free beta. Results are informational and should be verified against official payroll, union, pension-fund, employer, and tax records.
